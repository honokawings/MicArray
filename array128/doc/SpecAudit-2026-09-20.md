# M128 规格与界面核对

> 本文保留当时核对结论；后续按用户要求已实现 SYS3 串口收发，`uart_supported_by_host` 现为 `true`。当前行为与验证边界见 [Sys3Serial.md](Sys3Serial.md)，下文“尚未接入”仅描述此次核对时的历史状态。

核对来源：硬件仓库 `260902_MEMS_Array/README.md`（2026-09-20），以及该仓库的 `doc/host_protocol_reference.md`、`doc/system_uart_debug.md`。未改动硬件仓库，未下载位流，未发送控制命令。本文是软件符合性核对，不是电气或工业标准认证。

## 核对结果

| 项目 | README / 协议规格 | 上位机处理 |
|---|---|---|
| 设备 | MINI-200H / PG2L200H / IM72D128V01 | 新增只读硬件参考，不冒充设备识别 |
| 推荐位流 | MEMS_Array_uart_clk8_18v_spread3_long | 仅作参考；UDP 不报告当前位流身份 |
| PDM 时钟 | 3.072 MHz，8 路同源 CLK0–7 | 修复旧“四组、每组 32 通道”推断；实际负载分组未知 |
| 通道映射 | DATAk 对应 CH2k (LR=GND)、CH2k+1 (LR=VDD) | 原解码顺序正确；新增完整接口/Bank/FPGA 焊盘表，64 路焊盘逐项与 README 比较一致 |
| 接口 | J10 CLK、J25 DATA32–63 属 L6；J26 DATA0–31 属 L7 | 显示明确映射；不把 FPGA 焊盘号当排针序号 |
| 电气 | MEMS LVCMOS18 / 1.8 V；UART 3.3 V | 界面和指引区分两种电压；不设置/测量供电 |
| PCM | 128 CH / 48 kHz / signed PCM24 s24le Q1.23 | 协议、录制和通道排列一致，不改解码格式 |
| 有效通带 | 20 Hz–16 kHz，DC 保留 | 与 SRP 软件分析频带约 250–8000 Hz、频谱显示 0–24 kHz 分开说明 |
| 前处理 | CIC5 /8 → FIR63 /4 → FIR127 /2 → 增益/偏置校准 | 固定参考；板级默认增益 1、偏置 0 不等于主机监听增益 |
| 群延迟 | 2285.5 PDM 周期；t=(64×frame_id+63−2285.5)/3072000 | 时间公式一致；bit2 故障禁用有效时间，无数据不显示伪造时间 |
| UDP | M128 v1、1208 B、32 B 头、3×392 B 记录、16000 包/s | 严格解码及独立包/帧连续性审计保持不变 |
| 速率 | PCM 18.432 MB/s；UDP 19.328 MB/s；线路预算 163.072 Mbit/s | UI 实测明确标为 UDP 负载；规格列出 154.624 Mbit/s 与线路预算的区别 |
| 网络 | 设备 .2、主机 .1/24，源/目的端口 5000；1000M 全双工及 ARP 就绪 | 设置页集中配置监听/来源过滤；只改变 PC，不改 FPGA 或本机网卡 |
| SYS3 UART | COM3、115200 8N1、无流控，s/h/r/t/c | **尚未实现主机串口收发**；新增准确指引，PLL/PHY/ARP 显示未知；KEY0/KEY1 仅兼容保留 |
| 自测 | bit4 模式、官方 pattern_id=1、48000 帧数字验证 | 参考表和验收条件一致；不把 FPGA 已发出当作 PC 已收到，不把 PASS 当作声学或供电验收 |
| 机械坐标 | README 没有真实 128 阵元坐标 | 保持严格导入；未配置时显示“—”，不制造生产螺旋坐标 |

## 页面与交互调整

- 七个主页面：实时监测、声源定位、定向降噪、音频录制、离线分析、系统配置、设备诊断。
- 顶部固定状态与常用操作，网络设置移入“系统配置→接口设置”，阵列坐标与硬件规格分为独立子页；快捷按钮直达设置。
- 诊断使用“运行状态 / 通道质量 / 数据报文 / 联调指引”，日志按需展开。状态颜色同时配文字；数据故障优先于自测状态。
- 通道质量删除错误时钟分组，区分“零值数”和“全通道静音”；RMS、AC 使用 dBFS，DC 使用满量程比例。无数据不是无故障。
- 视场角和中心方向成对布局；四点表常显四行，不被操作按钮遮挡，保留拟合、撤销和文件操作。热力聚焦说明为显示参数，可信度阈值不绕过质量门控。
- 操作名称简短，单位直接进入标签，详细含义放入提示；整数、小数和下拉控件禁止滚轮误修改。

## 报告兼容性

`micarray128-diagnostics-v1` 保持原字段；通道 `clock_group` 改为 `null`（弃用错误推断），新增 `connector`、`io_bank`、`fpga_pad`。新增 `hardware_reference`，其中 `reference_only=true`、`detected_firmware=null`、`uart_supported_by_host=false` 明确标注来源与实现边界。下游读取者不得把参考电压/构建名视为当前设备测量值。

## 验证与边界

Release 构建、Qt 协议/处理/录制/UI 回归、128 通道映射与报告回归；1440×900 和 1120×700 的全部主页面与子页面渲染检查。四点末行完整可见，并检查按钮与表格不重叠；真实坐标、界面导航和滚轮保护均有测试。

README 明确最新八路 CLK / 1.8 V 位流尚未下载实机验证；之前 FPGA 自测 PASS 属于较早已下载位流，不能替代新版电气和时序验收。本次只执行软件构建、回归及无硬件操作的界面检查。USB 摄像头、真实 MEMS 声学表现和真实阵元坐标仍依赖现场条件。
