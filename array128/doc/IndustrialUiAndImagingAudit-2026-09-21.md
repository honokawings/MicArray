# M128 工业界面与声源成像工作清单

## 目标与边界

1. 完整删除 **128 版**离线分析页面、运行线程和生产依赖；保留录制能力及测试读取 WAV 的验证工具。旧 48 版不改动。
2. 全面优化各页面交互：信息层级、布局、键盘/鼠标操作、准备条件、错误反馈、运行/历史状态、参数约束、文件操作和退出安全；不以换配色代替交互改进。
3. 使用独立物理声场模型仔细验证 128 阵列成像：方向符号、精度、噪声/故障通道、不同几何和相机视角、热力峰与标记一致性、连续流状态隔离、最大网格性能。仿真通过不等于真实 MEMS/机械坐标的现场声学验收。

当前基线为 `SpiralArray / 3b508aa`。2026-09-21 SYS3 未提交改动保留；不创建分支、不 stage/commit。没有给出真实机械坐标或实采声学校验文件，不能编造默认阵列替代实物。

## 已发现的问题

- 页面路由使用裸数字，直接删除离线页会造成配置/诊断快捷入口错位；改为具名页面路由。
- 带通下限不小于上限时，DSP 静默旁路但 UI 仍显示勾选，必须修正交互与实际处理的一致性。
- 现有合成定位用例用 `s[n - dot(position, sourceDirection)]` 生成输入；真实位于正方向的声源靠近该方向的阵元会**更早**收到声音。需独立传播距离模型验证定位和波束符号，不能继续用同公式自证。

- 镜像复现：`build-array128/imaging-before.txt`，18个方向/SNR案例中16个非正前方案例失败；例如实际 +35°/-20° 被输出 -34.86°/+19.91°。原波束目标功率0.052、镜像功率0.995，符号修正后对应互换。
