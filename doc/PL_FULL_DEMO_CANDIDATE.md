# PL 全链降噪（固定演示参数）— V3 未发布候选

新增明确输入模式“PL 全链降噪（固定演示参数）”。配套 PL 路径为原阵列三波束→固定参数 Wiener→带通→LogMMSE→AGC。AUF1 已是最终 AGC 输出，上位机仅显示、录制、监听；保留原监听增益/音量边界，不再次调用 Wiener、BandPass、LogMMSE、AGC 的 process。

此目录独立于 R2，未部署到发布目录，也不表示 RTL、容量、完整布局布线或实机已经通过。完整软件、AUD3 三波束、AUW1 固定维纳混合模式及旧兼容模式分别保留，无自动回退。

## 唯一支持的后处理配置

- 带通开启：100–8000 Hz。
- LogMMSE 开启：2048 点、重叠 0.5、先验 SNR 平滑 0.98、噪声平滑 0.95、最小增益 −20 dB。
- AGC 开启：目标 −24 dBFS、最大增益 20 dB、最大衰减 −20 dB、启动 20 ms、释放 300 ms、限幅 −1 dB。
- 顺序严格为带通→LogMMSE→AGC；Wiener 只支持固定算法，单/双点及对应系数仍可调，方向可连续更新。

当前参数不匹配时，该输入模式明确报出原因并停止音频，不修改用户的参数、顺序或输入选择。需要其他设置时，由用户明确选择软件或 AUW1 混合模式。录制仅可选择“自动增益控制”这一最终节点；未上传的 Wiener、带通、LogMMSE 中间量不能被最终音频冒充。CH0 原始参考和最终降噪输出可继续显示/监听，A/B1/B2 标注未上传并禁用。

## 设备能力与控制

新 build 为 0x20261022。此候选显式识别新镜像 stage1、stage2、stage3，也保留旧 build20/21 对应模式。stage3 的 DNS1[33..36] 为固定演示配置指纹 0xb2c8f065；只有 build、阶段、CRC、指纹和已应用 COMMIT 都确认后才授权最终流。指纹对应集成目录的 canonical_profile.json，包含原 C++ binary64 常数和 Hann 表等内容，测试验证其 SHA256。旧 R2 可以明确拒绝新 build，不能把新能力伪装成旧版本。

九字段控制与 V2 相同，field6=2 表示全链；RESET→BEGIN→九字段→COMMIT 共 12 个逐 ACK 命令。仅方向变化为 11 个命令，保留 stream_id 和所有 DSP 历史；算法、单/双点及系数变化要求 RESET 新流。所有原会复位 DSP 的设置变化同样复位两端；不兼容后处理参数直接拒绝，不发一组偷偷替换的参数。

AUF1 41 字节格式为 version1/flags0x31，stream_id[6..7]、首样本号[8..11]、数量1..6[12]、float32[13..36]、保留零和 CRC8。沿用严格连续索引、有限浮点、旧流计数、ACK 前真实样本缓冲及错误停止处理，不做静默回退。

输出索引0包含原 LogMMSE 初始2048个零，不能裁掉或重复添加。真实 Log 按1024点 hop处理，停止录音时可有不足1024点的真实内部剩余，另有上位机最多199点重组尾部；这与丢样分别统计，不用零补尾强行对齐。

## 当前验证

test_plfull 覆盖固定配置逐项拒绝且不改变设置、持久化、能力清单指纹、build22各阶段、九字段 mode2、方向连续、系数复位、提前 AUF1、错误阶段/CRC/保留值/非有限/缺样拒绝。四段原黄金 final 各143360点通过实际 Worker final入口，输出逐float32 bit一致，证明上位机没有重复进行降噪；只上传最终AGC节点时拒绝伪造中间录音。

页面测试检查实际 GUI→控制→队列→Worker、固定输出不再后处理、用户改成不兼容 FFT 参数后仍保存原选择并明确拒绝、错误远端指纹不启动。原 R2 的任意 TCP 分片修复、已有定位、镜头、热力图与旧模式回归均保留。

以上是 host/软件候选验证。完整 V3 实际 RTL 旁带 fixture 的跨端检查、完整链误差、容量、最坏 hop 周期、完整 route/DRC 与实机听感仍需各自当前证据。候选源只使用独立 MicArrayPLFullV3Trial 便携设置，原工程、Stage1、V2-R1、V2-R2 均不覆盖。
