# PL 固定维纳与上位机原后处理（候选）

本目录为独立 R2：修复原 ProtocolCodec 在两字节 `7e7e` 帧头被 TCP 拆成两次到达时丢弃第一个 `7e` 的问题。现在无完整帧头时只保留末尾可能的一个 `7e`，仍丢弃其余垃圾，最大合法 payload 边界不变。新增逐字节、随机分片、合并多帧、垃圾后跨 chunk 同步及最大缓冲边界测试，并用真实 top/vendor 仿真的 105600 个 transport words 通过实际 Codec→PlDenoiseTransport 检查；不修改任何原 DSP 数学运算。原 R1、Stage1 包不被覆盖。

本候选增加 **PL 固定维纳 + 上位机原后处理（AUW1/DNS1）** 输入模式。PL 执行原 48 通道四点 Lagrange 三波束 A/B1/B2 及固定参数 Wiener（1024 点、512 点步长）；PC 仅执行原带通、LogMMSE、AGC，顺序、参数、监听增益沿用用户设置，不再执行 Wiener。完整软件模式、上一版 AUD3 三波束模式和旧设备 CH1/2/3 兼容模式分别保留，不会自动切换或冒充硬件输出。

只支持固定参数维纳。选择自适应维纳时明确停止该 PL 模式并说明原因；需要自适应时由用户明确选择 AUD3 或完整软件模式。此模式只上传单声道维纳结果及原始 48 通道，不上传 A/B1/B2 波束；三路波束的绘图/监听选项标注未上传并禁用，不能拿原始 CH1/2/3 代替。CH0 原始参考及最终降噪输出可继续对比。

## 使用与配置生命周期

启用降噪、连接配套 bit、解锁控制，选择上述 AUW1 模式，等待状态显示“已就绪”。初次使用、重连或手动重新同步发送 RESET，然后 BEGIN、九字段、COMMIT，共 12 条逐 ACK 控制命令。字段 0..5 为原坐标与 directionFromAngles float 向量计算出的六个 Q26 斜率；字段 6 为 PL 模式；字段 7、8 为单点/双点对应抑制系数 Q16。每条仍为 26 字节原控制帧，CRC16 检查，150 ms 超时重发同一命令，最多 8 次。

正常调整方向发送 BEGIN、九字段、COMMIT 共 11 条，不 RESET、不清除任何 DSP 历史。活动 cfg_id 改变，stream_id 保持不变，Wiener 输出样本号连续。原程序会触发 resetProcessing 的参数变化（抑制模式/算法/系数、带通、LogMMSE、AGC、节点顺序、启停、输入模式等）在此模式同步 RESET 两端，再配置新 stream_id。只更改绘图源、监听源/增益/缓冲不复位 PL。不会为掩盖差异另改演示参数。

配置先收到了音频、后收到 COMMIT ACK 时，保留新 stream_id 的真实开头，待 ACK 后按序释放。RESET ACK 可暂时显示 stage1，随后必须收到 stage2 已应用的 COMMIT ACK；转换中的 AUD3 不会被误送到单声道后处理。

## 协议与故障显示

AUW1 41 字节包放在原 CH7..47 高字节，格式 version1/flags0x21，包含 stream_id、首样本号、1..6 个 mono float32、保留零和 CRC8。DNS1 stage2/build0x20261021 提供 active_cfg、ACK、ready/busy/error、溢出、stream_id 及 Wiener 帧数。原低 24 位、48 通道编号与 PS 转发路径保持原约定。

接收端检查版本、格式、保留字节、CRC、有限浮点、stream_id 以及连续样本号；从 0 开始重组真实 200 点块。过期 stream 明确计数丢弃，不补零、不作为新流。新流缺开头、缺样/重复、音频 CRC 错误、非有限值、溢出或设备错误均停止 PL 输出并显示原因，使用“重新同步PL方向”恢复。配置写入期间 control CRC error1 可由 PS 分字写的暂态引起，使用同事务重发而不隐式换算法。

固定维纳第一输出 hop 对应原 Wiener 时间线 0，收满 1024 输入后首次输出 512 点，此后每 512 点一 hop。没有尾部补零或 flush。上位机按实际点数连续执行原后处理，流末不足 200 点暂存于传输重组器；离线验证将最后真实短块直接交 Worker 验证完整输出，未补造样本。

## 验证范围

`test_plwiener` 覆盖九字段、单/双点系数、RESET 阶段转换、提前音频、方向连续 stream、参数复位、自适应拒绝、损坏/过期流；四段原 GitHub Wiener 输出通过 AUW1 及实际 Worker 后处理，与原各级黄金逐 float32 完全一致。`test_pldenoise_ui` 额外覆盖 GUI/线程入口、丢 COMMIT ACK 重发、参数新 stream、单声道不再次 Wiener、未上传波束标签。

`tools/evaluate_worker_stage2.py` 将四段、每段 143360 点的真实 Xilinx bit 模型 Wiener 流送入实际 Worker 单声道入口，比较带通、LogMMSE、AGC 及最终输出。固定演示参数下最终最大绝对误差不超过 6.60e-8，误差 SNR 最低 91.43 dB，无时移/增益拟合。全部原始 Wiener 浮点输入各级与黄金完全相同。项目内部数值门槛为最大误差 ≤1e-6、无拟合误差 SNR ≥80 dB（或完全一致）、RMS 电平差 ≤0.001 dB、点数相同且无非有限数；这是实现误差门槛，不是听感或行业性能标准。

结果仅对应冻结 profile（两点固定系数 5+5、100..8000 Hz 带通、LogMMSE 2048、原 AGC 和节点顺序）及这四段录音。其他系数存在 Q16 量化误差，不能凭本结果宣称所有声音、所有设置完全无差别。Qt 部署/离线仿真通过、PL 综合布局布线、bit 和实机音频验收分别记录；本 host 包不证明已上板，也不代表全部降噪已经迁入 PL。

本程序使用独立便携 INI 及 MicArrayPLWienerR2Trial 配置名，首次只读取旧配置，不改旧版本注册表。原相机、定位、热力图生产源码保持复制版本行为。建议演示时只开一个监听程序，避免两路扬声器回放和设备连接竞争。
