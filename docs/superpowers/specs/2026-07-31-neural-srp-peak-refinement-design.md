# 神经网络 SRP 主峰锐化与亚网格定位设计

## 目标

在现有单声源鲁棒 SRP-PHAT、连续八点 sinc 精修和 Hessian 不确定度基础上，
增加一个可训练、可审计、纯 CPU 的神经网络后处理器。它读取主峰附近的局部
SRP 响应，预测小范围方向残差、主峰二维宽度、相关项和神经可信度，用于：

1. 修正规则网格采样、混响肩峰和坏通道残留造成的系统性亚网格偏差。
2. 让显示热力图的主峰中心与最终方向一致，并缩小主峰半功率面积。
3. 保持现有物理定位器、可靠度门控、时间一致性和无模型回退能力。

本阶段仍只考虑一个主声源，不进行声源计数、分离或多峰检测。

## 研究依据

- [Neural-SRP](https://arxiv.org/abs/2403.09455) 表明学习模型可以与 SRP 的
  物理灵活性结合，并通过模拟数据与迁移学习提高混响环境定位表现。
- [CNN-based Robust Sound Source Localization with SRP-PHAT for the Extreme Edge](https://arxiv.org/abs/2503.02046)
  说明 SRP 特征和紧凑神经网络可以在边缘 CPU 上实现低延迟推理。
- [Deep Cross Correlations](https://arxiv.org/abs/2006.05447) 说明对相关函数或
  其派生空间响应进行学习式修正，可以在训练/测试条件不完全匹配时改善定位。
- [SRP 带宽与空间分辨率分析](https://arxiv.org/abs/2402.06586) 说明 SRP 图是
  对带限 GCC 的空间采样，网格分辨率与有效带宽共同决定主峰采样误差。因此
  网络只能学习采样和扰动残差，不能替代物理带宽、阵列孔径和前后半球约束。

## 方案比较

### 方案 A：外置 ONNX 编解码网络

优点是模型表达能力和生态完整。缺点是当前项目没有 ONNX Runtime，新增运行库
会显著增加发布体积、部署步骤和故障面；对只处理单个局部峰而言也明显过度。

### 方案 B：嵌入式物理引导小网络（采用）

使用固定结构的小型多层感知机处理 `9×9` 局部 SRP 补丁和物理诊断量，权重作为
版本化 C++ 数据嵌入程序。训练工具独立运行，正式应用不依赖 Python、ONNX、
Torch、GPU 或外部模型文件。推理规模约几千个权重，容易保持实时性能。

### 方案 C：手工反卷积或软最大值

依赖最少，但无法从混响、坏通道和带宽变化形成的非理想峰形中学习残差，也不满足
“增加神经网络后处理”的要求，仅适合作为基线。

## 总体数据流

```text
48 通道音频
  -> 通道质量门控 / 相干 PHAT / 多基线 SRP
  -> 物理连续峰 + Hessian + 可靠度
  -> 以物理峰为中心采样 9×9 局部 sinc-SRP 补丁
  -> NeuralSrpPeakRefiner
       -> 方位/俯仰残差
       -> 方位/俯仰峰宽缩放
       -> 相关项
       -> 神经可信度
  -> 物理约束与安全门控
  -> 最终连续方向 + 神经锐化 SRP 图
  -> 离线照片标记 / 实时视频热力图
```

网络不接触原始音频，也不重新估计多通道时差。物理 SRP 始终先完成，网络只处理
已经通过单声源空间证据检查的局部主峰。

## 局部补丁与特征

### 补丁采样

在物理连续峰的局部切平面上构造 `9×9` 网格。方位、俯仰步长分别取对应物理
Hessian 标准差的 `1/2.5`，并限制在 `0.25°..1.5°`。步长不依赖显示网格，确保
`locate()`、离线分析和任意分辨率的实时热力图得到相同神经方向。每个位置使用
全部有效基线和现有八点 Hann-windowed sinc 目标函数重新评分，不使用低精度
三次插值。

补丁按中位数和 `P95` 做稳健归一化，并保留中心值、局部最大值和动态范围。无效、
非有限或动态范围不足的补丁不进入网络。

### 网络输入

- `81` 个归一化局部 SRP 值。
- 物理连续峰的归一化方位角和俯仰角。
- 方位/俯仰采样步长。
- 物理 Hessian 的两个标准差和相关系数。
- 现有可靠度、峰旁瓣比、全阵列相干度和有效通道比例。

所有标量均使用模型内固化的训练集均值与尺度标准化，并在推理前夹到训练范围。

## 网络结构与输出

模型采用两层隐藏层的紧凑残差 MLP：

```text
标准化输入
  -> Dense(48) + tanh
  -> Dense(24) + tanh
  -> Dense(6)
```

输出解释如下：

1. `deltaAzimuthCell`：经 `tanh` 限制到 `[-1,+1]` 个补丁单元。
2. `deltaElevationCell`：同上。
3. `azimuthSigmaScale`：映射到 `[0.35,1.0]`。
4. `elevationSigmaScale`：映射到 `[0.35,1.0]`。
5. `correlationResidual`：限制到 `[-0.35,+0.35]`。
6. `neuralConfidence`：sigmoid 映射到 `[0,1]`。

模型参数量控制在 `8192` 个 float 以内，嵌入权重和归一化常量不超过 `32 KiB`。
模型数据包含格式版本、训练种子、训练样本数和 64-bit 校验值。

## 训练与模型导出

新增可选 CMake 目标 `train_neural_srp_peak`，不进入默认应用构建。训练工具：

1. 使用固定随机种子和固定 8 分片生成覆盖正面半球的单声源信号，结果不依赖
   主机 CPU 核数；数据按 50% 标称、
   20% 单坏通道、20% 双坏通道和 10% 四坏通道分层，并随压力等级提高反射
   增益和噪声强度。
2. 信号按 80% 随机多音、10% 密集宽带和 10% 带限分层，使用互质步进与坏通道
   层打散；随机加入白噪声、单次反射、幅值失配和不同有效带宽。
3. 通过正式 `RobustSrpPhatScorer` 生成物理连续峰与局部 sinc-SRP 补丁，不使用
   另写的近似 SRP。
4. 以真实方向减去物理峰的残差、目标锐化尺度和样本有效性作为监督信号。
5. 按固定种子划分训练、验证和完全独立测试集合，禁止测试样本参与早停或归一化；
   独立测试重新执行物理 SRP 和全部生产门控，不用训练期近似指标代替。
6. 使用 Adam、Huber 方向损失、峰宽损失和可信度二元交叉熵训练。
7. 导出 `src/analysis/neuralmodeldata.h` 以及机器可读的
   `doc/neural-srp-peak-v1-training-report.json`；头文件与报告先在临时目录生成，
   再成对替换，第二项写入失败时恢复原文件。正式仓库只保留通过验收的确定性模型。

峰宽监督目标为 `0.5` 个补丁单元，并以 Huber 损失训练。可信度正样本必须同时
满足：真实角度残差不超过 `1.5°`、物理可靠度合法、补丁动态范围合法；网络方向
输出仍严格截断到一个补丁单元，其他样本作为旁路负样本。

训练工具必须支持 `--self-test`：使用极小数据集完成前向、反向、一次权重更新、
跨运行确定性复现、成对导出回滚，以及导出黄金值与正式 `NeuralSrpPeakRefiner`
在 `1e-6` 内一致的检查。正式独立测试少于 256 个样本时拒绝导出。

## 推理门控与回退

神经修正只有同时满足下列条件才被接受：

- 用户启用神经后处理，模型版本与校验值合法。
- 物理定位本身 `hasDirection`，且可靠度不低于现有配置门限。
- 局部补丁完整、有限且动态范围充足。
- 神经可信度不低于 `0.55`。
- 修正量不超过一个补丁单元，也不超过 `1.5°`。
- 修正方向位于物理 Hessian 的 `2.5σ` 椭圆内。
- 修正方向的物理 sinc-SRP 分数不低于原峰分数的 `97%`。
- 修正后仍位于正面半球和配置视场的合法角度范围。

任一条件失败时，方向、协方差和热力图全部使用现有物理结果。网络永远不能把
原本无方向、静音、漫射噪声或无效窗口变成有效声源。

## 方向融合与主峰锐化

接受网络结果后，最终残差按
`配置强度 × 神经可信度 × 物理可靠度` 与物理方向融合。网络不能覆盖物理方向，
最大只执行受限残差修正。

热力图主峰使用网络预测的二维峰宽和相关项生成局部 Mahalanobis 核：

- 核中心严格使用最终融合方向。
- 峰值幅度不超过原始主峰。
- 在主峰 `3σ` 之外完全保留原始 SRP。
- 在主峰内部对肩部执行有界幂次抑制，再与预测核取较大值。
- 所有值最终限制到 `[0,1]`，并保持非有限值拒绝逻辑。

定位向量、`SpatialResponseResult::refinedPeak`、Hessian、神经核中心和 UI 标记
必须来自同一缓存结果，不能增加独立时间平滑。

## 配置与 UI

离线分析和实时定位设置分别新增：

- `neuralPeakEnhancementEnabled`，默认 `true`。
- `neuralPeakEnhancementStrength`，范围 `[0,1]`，默认 `0.30`。

实时定位面板新增“神经主峰增强”复选框和“增强强度”数值控件；离线分析页提供
相同开关。设置写入稳定的 `QSettings` 键，未知或非法值回退默认值。

任何神经配置变化都开启新的定位 generation、清空旧方向和旧热力图，并清除
评分器时间状态，防止异步回灌旧配置结果。

诊断结果增加：

- 是否实际采用神经修正。
- 神经可信度。
- 神经方向修正角度。
- 神经峰宽缩放。

这些字段用于测试与状态显示，不改变设备协议。

## 错误处理

- 模型校验失败：记录一次明确状态并回退物理路径，不终止定位线程。
- 输入尺寸、数值或归一化异常：本帧旁路神经路径。
- 输出非有限、越界或可信度不足：本帧旁路。
- 配置关闭：不采样神经补丁，避免无意义 CPU 开销。
- 训练工具失败：不覆盖已有模型头文件和训练报告。

## 测试与验收

### 数值与安全

- 固定黄金输入验证 C++ 前向结果和导出器一致。
- 零输入、常量补丁、NaN、Inf、尺寸错误全部安全旁路。
- 修正量、峰宽、相关项和输出热力图严格在约定范围。
- 关闭神经增强时结果逐值等于现有物理路径。
- 静音、漫射噪声、窄带歧义和通道不足不会被网络变成有效方向。

### 精度

使用未参与训练与早停的确定性测试集，至少包含 `256` 个方向与扰动组合：

- 相比规则网格 argmax，神经结果的中位角误差至少降低 `30%`。
- 相比当前物理连续峰，神经融合结果的中位角误差至少降低 `0.3%`。早期未量化、
  无连续前窗且分层未完全交叉的探索评估曾显示约 `2.77%`，但该数字不作为正式
  证据。正式口径要求先量化为运行时 `float`，使用默认 `0.35` 时序平滑，并让
  坏通道、信号类型、边缘和反射分层交叉；在不人为劣化全组八点 sinc 物理基线
  的前提下，验收值按严格生产等价实证修订，同时保留相对网格 `30%` 和 P95
  安全门禁。
- 相比当前物理连续峰，P95 角误差不得增加超过 `0.05°`。
- 边缘视场、反射、三类信号和 0/1/2/4 坏通道分别报告结果；每桶至少保留
  `24` 个样本，每个桶的中位数和 P95 相对物理结果都不得恶化超过 `0.05°`，
  不能只用总体指标掩盖退化。

正式 v1 的 512 个生产等价独立样本中，网格、物理连续峰和神经融合的中位误差
分别为 `0.364232°`、`0.213979°` 和 `0.213062°`；相对网格改善 `41.50%`，
相对物理连续峰改善 `0.43%`。物理和神经 P95 均为 `1.684582°`，
396/512 个候选修正通过全部生产门控。训练候选先在独立生产验证集上与量化暖
启动模型比较，只有中位误差再改善至少 `5%` 才能替换；本版验证选择稳定暖启动
权重，之后才执行上述独立测试。上述结果仅代表严格但有限的确定性声学仿真。

如果模型不能满足“相对物理连续峰至少提升 0.3%”，不得以仅改善显示效果代替
定位精度验收；必须继续调整训练分布、特征或融合门控。

### 热力图

- 神经增强后的主峰中心与最终方向距离不超过 `0.25°`。
- 可靠样本的主峰半功率面积中位数至少缩小 `25%`。
- 主峰外 `3σ` 区域逐值保持原始 SRP。
- 低可靠度或神经旁路时不生成额外尖峰。

### 性能

- Release 下单次神经补丁采样、推理和锐化的中位额外耗时不超过 `2 ms`。
- `640×360` 实时增强总中位耗时继续不超过 `100 ms`。
- `640×360` 高精度总中位耗时继续不超过 `200 ms`。
- UI 缓存重绘门禁保持通过。

### 全量回归

- Debug 全量构建。
- CTest 全部通过。
- 训练工具 `--self-test` 通过。
- Python 工具测试与模拟设备服务端自检通过。
- `git diff --check` 通过。

## 非目标和物理限制

- 不增加多声源检测、分类、跟踪或语音内容识别。
- 不引入 GPU、云推理或运行时下载。
- 不声称突破阵列孔径、信号带宽或共面阵列的前后镜像物理限制。
- 没有真实标注数据时，模型的首版证据来自确定性声学仿真；后续真实现场数据可用
  同一训练工具再训练，但不能在本阶段虚构真实环境提升结论。
