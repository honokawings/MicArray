# 演示全屏与深色主题设计

## 目标

增强现有“演示全屏”功能，使其成为适合展示实时音视频与阵列状态的清爽全屏界面；同时为整个程序增加可持久化的浅色/深色主题切换。

## 演示全屏

采用现有监控页原位切换布局，不创建第二窗口，也不搬移或复制媒体控件。

进入演示全屏时：

- 自动切换到“音视频融合”页并进入操作系统全屏。
- 保留顶部状态带中的连接状态、设备端点、心跳、接收速率和健康状态。
- 保留中间区域的视频、音频波形、阵列幅值热力图和 60 秒趋势图。
- 保留主题灯泡按钮和“退出全屏”按钮。
- 隐藏左侧设备连接、控制接口和音视频设置区域。
- 隐藏右侧诊断、告警时间线和日志区域。
- 隐藏顶部错误计数、导出诊断按钮、主页面签栏和底部日志状态栏。
- 中间媒体区域自动占满剩余空间。

退出演示全屏时恢复所有隐藏区域、页签栏、窗口状态和进入前的分隔比例。用户可通过“退出全屏”按钮、双击视频或 `Esc` 键退出。重复进入和退出不得破坏布局。

演示模式只改变界面呈现，不停止网络、协议、音频、视频、录制、分析或声源定位线程，不清空诊断、告警和日志数据。

## 浅色/深色主题

在顶部状态带右侧增加无文字的普通灯泡图案 `QToolButton`。

- 浅色主题下按钮显示亮灯泡，提示“切换到深色模式”。
- 深色主题下按钮显示轮廓灯泡，提示“切换到浅色模式”。
- 点击后立即切换整个应用的 `QPalette` 和统一样式表。
- 主题覆盖主窗口、标签页、分组框、输入控件、按钮、列表、文本框、滚动条和工具提示。
- 视频背景、热力图色阶、声源定位覆盖层等具有业务含义的深色可视化保持其专用配色，但边框、标题和外围容器随主题协调变化。
- 主题选择通过 `AppSettings` 写入本地配置，下次启动自动恢复。
- “恢复全部默认设置”将主题恢复为浅色。

灯泡图案由代码绘制，不依赖外部图片文件、字体图标或新增第三方库；图标需在不同 DPI 下保持清晰。

## 代码边界

- 新增独立主题辅助模块，负责主题枚举、调色板、样式表和灯泡图标生成，避免把样式字符串继续堆积到 `MainWindow`。
- `AppSettings` 只负责主题值的读取、校验、保存和重置。
- `MainWindow` 负责创建主题按钮、应用主题以及切换演示布局。
- 监控页左右区域、中心区域、状态带和诊断导出按钮保存为成员指针，以便可靠切换可见性。
- `MainWindow::keyPressEvent()` 仅在演示模式下拦截 `Esc`；其他按键继续交给基类。

## 错误处理与兼容性

- 配置中缺少主题、主题值损坏或主题值未知时回退为浅色。
- Qt 最低版本保持 6.5，使用 C++20，不增加外部依赖。
- 保持现有对象名和测试可依赖接口；新增控件使用稳定对象名。
- 不创建分支、不提交，不覆盖或回滚工作区已有改动。

## 测试与验收

- UI 测试验证进入演示模式后窗口全屏，状态带和中心可视化可见，左侧区域、右侧诊断区域、错误计数、导出诊断和页签栏隐藏。
- UI 测试验证点击退出、双击视频和按 `Esc` 均可恢复普通窗口及全部原布局区域。
- UI 测试验证灯泡按钮存在、无文字、具有图标和正确提示，点击后主题属性与样式发生切换。
- 设置测试验证主题默认值、保存/载入、非法值回退和 `resetAll()` 恢复浅色。
- 运行完整 CMake 构建、CTest、Python 工具测试、模拟设备自检和 `git diff --check`。
- 同步更新 `doc/Readme.md` 的 UI 说明和变更记录。
