# 精细化四点视频校准与校准档案设计

## 目标

增强“声源定位”页面的四点视频校准工作流，使用户能够检查和撤销采样点、在校准完成后隐藏校准点，并通过独立 JSON 文件手动保存或载入校准值。现有自动保存和启动自动载入行为继续保留。

## 校准工作流

四点校准仍使用“稳定声源方向 + 视频点击坐标”的物理视角拟合方式。开始校准后：

- 当前采集点和已接受点始终显示在视频上，不受“显示校准点”开关影响。
- 页面显示四行点位明细，包含序号、方位角、俯仰角、平均置信度、方向波动以及归一化视频坐标。
- 未采集行显示为空；被拒绝的点击不写入点位明细。
- 增加“撤销上一点”按钮，仅在至少存在一个工作样本且尚未完成拟合时可用。
- 撤销后删除最后一个工作样本，进度和视频叠加同步回退。
- 取消校准仍恢复已保存校准结果，不修改当前正式参数。

第四点通过质量检查后继续使用现有五参数拟合。拟合失败时保留四个工作样本，允许撤销最后一点并重新采集；不覆盖当前正式参数。拟合成功后：

- 更新中心方位角、中心俯仰角、水平视场角、垂直视场角和滚转角；
- 保存四个样本、RMS 和参考视频尺寸；
- 结束采集模式并自动隐藏正式校准点；
- 用户可通过“显示校准点”重新查看点击点、预测点和误差连线。

## 校准点显示

`LiveLocalizationSettings` 增加 `showCalibrationOverlay`，默认 `false`。该开关只控制正式校准结果的四个点击点、预测点和误差线：

- 校准进行中始终显示工作样本；
- 校准成功后自动设为隐藏并保存；
- 用户手动切换后立即更新视频并保存；
- 隐藏校准点不会隐藏实时声源标记或空间响应热力图；
- 下次启动恢复上次显示状态。

## JSON 校准档案

新增独立 `VideoCalibrationProfileStore`，负责无 UI 的序列化、原子写入、读取和校验。页面只负责文件选择、应用结果和显示错误。

文件顶层字段：

- `format`: 固定为 `MicArrayVideoCalibration`
- `version`: 当前为 `1`
- `savedAtUtc`: ISO 8601 UTC 时间
- `array`: `rows=6`、`columns=8`、`spacingMeters=0.05`
- `camera`: 五个 `CameraViewSettings` 数值
- `referenceVideo`: 保存时的视频宽度和高度；没有视频时为 `0×0`
- `calibrationRmsPixels`: 非负有限数值
- `samples`: 空数组或恰好四个元素

每个样本包含：

- `azimuthDegrees`
- `elevationDegrees`
- `normalizedX`
- `normalizedY`
- `confidence`
- `angularDeviationDegrees`

导出使用 `QSaveFile` 原子替换目标文件，避免写入中断留下半文件。用户可以导出仅包含手动视角参数的档案，此时 `samples` 为空、RMS 为零。

## 载入与校验

载入流程先解析到临时对象，完整通过以下检查后才修改页面：

- JSON 必须是对象，格式标识和版本必须匹配；
- 阵列必须为 6×8、间距 0.05 m；
- 五个相机参数必须有限且满足 `CameraViewSettings::isValid()`；
- 参考视频尺寸必须为非负整数；
- RMS 必须为非负有限数值；
- 样本数量只能为 0 或 4；
- 样本角度、置信度、方向波动和归一化坐标必须满足现有配置边界；
- 四样本档案还必须通过点间方向距离和视频距离检查。

任何检查失败时返回具体错误，页面保持原参数、样本、网格和自动配置不变。成功后：

- 替换正式相机参数、校准样本、RMS 和参考视频尺寸；
- 更新参数控件、投影、方向网格、点位明细和 RMS；
- 保持用户当前的“显示校准点”选择；
- 同步写入现有 `AppSettings`，使下次启动自动恢复。

## 页面交互

四点校准区域增加：

- “撤销上一点”按钮；
- “显示校准点”复选框；
- 四行点位明细表；
- “导出校准”按钮；
- “载入校准”按钮。

导出和载入使用 `QFileDialog`。成功或失败结果显示在校准进度标签；文件操作取消不修改状态也不显示错误。导出默认文件名包含当前日期时间。

## 文件边界

- `src/analysis/calibrationprofile.h/.cpp`：档案数据结构、JSON 编解码、原子文件读写和校验。
- `src/app/appsettings.h/.cpp`：显示状态和参考视频尺寸持久化。
- `src/ui/livelocalizationpage.h/.cpp`：按钮、复选框、点位表、撤销、导入导出和状态应用。
- `src/ui/livelocalizationview.*`：继续只接收页面筛选后的校准样本，无需了解持久化。
- `tests/analysis/test_audioanalysis.cpp`：JSON 往返、非法文件拒绝和原子载入语义。
- `tests/app/test_app.cpp`：新增配置字段持久化和边界回退。
- `tests/ui/test_dashboard.cpp`：控件、撤销、显示开关和载入应用行为。

## 验证

- JSON 完整四点档案和仅相机档案均可往返。
- 损坏 JSON、错误版本、错误阵列、非法相机、非法样本数和非法坐标均被拒绝且不修改现有状态。
- 工作样本可逐点撤销，正式样本不受影响。
- 校准成功后正式校准点自动隐藏，重新勾选后恢复。
- 手动载入立即更新参数并自动保存。
- 完整执行 Debug/Release 构建、全部 C++/Python 测试和模拟服务器自检。
