# 降噪方向连续角度标记设计

## 目标

降噪页面中的增强方向 A、抑制方向 B1 和 B2 使用连续实际角度作为唯一业务状态。用户点击视频任意有效位置时，标记必须停留在对应位置，不得因为设备控制接口分辨率较低而吸附到量化网格。设备接口码只用于只读显示和发送控制帧。

## 数据模型

新增连续方向类型，分别保存 `double azimuthDegrees` 和 `double elevationDegrees`。`NoiseReductionSettings` 中的 A、B1、B2 改为连续方向，不再把 `qint16` 接口码作为持久化主状态。

连续角度必须为有限数，并夹紧到当前 `DirectionControlMapping` 的实际角度范围。默认范围保持方位角 `-90..90°`、俯仰角 `-45..45°`。

`DirectionControlMapper` 保留角度到接口码的线性映射、四舍五入和夹紧规则：

- 方位接口码范围为 `-4..4`。
- 俯仰接口码范围为 `-3..3`。
- 仅只读接口码刷新和控制帧发送调用量化函数。

## 页面交互

原有六个整数接口码输入框改为六个可编辑实际角度输入框，使用 `QDoubleSpinBox`：

- A、B1、B2 各有方位角和俯仰角。
- 支持小数输入，显示角度单位。
- 输入范围跟随当前实际角度映射范围。

每个实际角度输入旁显示对应的只读接口码。实际角度、映射范围或视频点击位置变化时，接口码立即重新计算，但不得反向覆盖连续角度。

用户选择 A、B1 或 B2 后点击视频有效区域：

1. 使用当前相机视角反投影得到连续方位角和俯仰角。
2. 将连续角度夹紧到可发送范围并写入所选方向。
3. 标记直接使用连续角度投影，因此保留点击位置精度。
4. 更新只读量化码。
5. 按既有规则自动发送全部六路控制值。

手动编辑实际角度时更新标记与只读接口码，但不自动发送；用户仍通过“发送当前方向”按钮发送全部六路值。

## 标记显示

`NoiseReductionVideoWidget` 接收三组连续方向。标记位置直接由连续方向投影，不经过接口码反算。

标记文本同时显示：

- 未量化的实际方位角、俯仰角，保留一位小数。
- 当前映射得到的方位接口码、俯仰接口码。

标记显隐和当前目标高亮规则保持不变。

## 配置持久化与兼容

新配置保存三组连续角度。加载时优先读取连续角度字段。

为兼容当前工作区已经产生的降噪配置，如果连续角度字段不存在但旧接口码字段存在，则使用当前映射将旧接口码反算为连续角度。首次保存后写入新字段。非法、非有限或越界字段逐项回退到默认值或夹紧到有效范围，不影响其他配置。

实际角度范围发生变化时，现有三组连续方向立即夹紧到新范围并保存；接口码随之刷新。

## 控制发送

`NoiseReductionPage::currentControlValues()` 在调用时把 A、B1、B2 的连续角度量化为六路 `ControlValues`。主窗口与协议层不保存连续方向，只接收最终量化值，因此现有控制帧格式和设备协议保持不变。

## 测试

增加以下回归覆盖：

- 一个不落在接口量化网格上的视频点击，标记连续角度与反投影结果一致。
- 点击后量化码正确，但连续角度不等于量化码反算角度。
- 手动输入小数实际角度后，标记保持连续值，只读码正确。
- `currentControlValues()` 和发送信号包含正确的六路量化值。
- 连续角度保存并重新加载后精度保持。
- 旧接口码配置可迁移为连续角度。
- 修改映射范围会夹紧连续角度并刷新输入范围和接口码。

## 非目标

- 不修改设备六路控制协议。
- 不提高设备接口码分辨率。
- 不改变相机反投影算法。
- 不改变降噪算法、音频线程、监听或频谱功能。
