# 实时定位页签与热力聚焦设计

## 目标

重新组织声源定位页面右侧控制区，使实时定位和视角校准职责清晰；提供可持久化的
热力图聚焦参数；保证四点校准表格四行常态可见，不依赖纵向滑动查看。

## 页面结构

右侧控制区改为对象名 `liveLocalizationControlTabs` 的 `QTabWidget`，包含两个页签：

1. `liveLocalizationRealtimeTab`，标题“实时定位”。包含现有实时定位分组及全部定位、
   显示方式、空间精度、热力图、网格、更新周期、置信度和神经锐化控件。该页内容
   允许在窗口高度不足时整体纵向滚动。
2. `liveLocalizationCalibrationTab`，标题“视角校准”。包含“视频视角参数”和
   “四点视频校准”两个分组，不使用包裹整页的纵向滚动区。

右侧页签区最小宽度为 `520 px`、最大宽度为 `680 px`，由水平分隔器保留视频区域的
伸缩空间。四点表格保持 4 行、7 列，列宽采用等比例拉伸；垂直滚动条始终关闭，
最小高度按水平表头、四行内容和边框动态计算，确保四行在正常布局中同时可见。
应用主题、字体或 DPI 相关样式变化后异步重算实际表头与逐行高度，避免构造期尺寸
在后续全局主题下失效。

## 热力图聚焦

`LiveLocalizationSettings` 新增 `heatmapFocusExponent`：

- 范围 `[0.5, 4.0]`，默认 `1.5`。
- 稳定设置键为 `liveLocalization/heatmapFocusExponent`。
- 非有限或越界值独立回退默认值，不影响其他设置。

实时定位页新增对象名 `liveHeatmapFocusSpin` 的双精度控件，显示标签“热力聚焦强度”，
步长 `0.1`、一位小数，并说明 `1.0` 为原始响应、数值越大越聚焦。

渲染阶段对最终用于着色的归一化响应执行：

```text
displayValue = pow(clamp(responseValue, 0, 1), heatmapFocusExponent)
```

映射同时作用于基础热力和精化峰合成后的数值，保持 `0` 和 `1` 不变。该参数只改变
颜色分布，不修改 `LiveSpatialResponse`、方向估计、置信度或空间网格；修改时仅使热力图
缓存失效并立即重绘，不启动新 generation，也不重配置工作线程。

## 兼容与错误处理

- 旧配置没有新键时使用默认 `1.5`。
- 聚焦参数设置为非法值时使用默认值，渲染函数仍对传入值做范围保护。
- 现有对象名和信号保持不变，新增页签和聚焦控件使用稳定对象名供自动化测试定位。
- 相机参数、四点校准数据、保存/载入流程和视频覆盖层行为不变。

## 测试与验收

- 设置往返保存聚焦强度；NaN、`0.4`、`4.1` 均独立回退 `1.5`。
- 页面只有“实时定位”和“视角校准”两个右侧控制页签；相机和校准控件属于
  “视角校准”，聚焦控件属于“实时定位”。
- 1200×700 常规窗口下校准表四行同时可见，垂直滚动条不可见且不可用。
- 页面构造后增大表格字体和表头内边距，四行仍全部可见且无需滚动。
- 相同响应在聚焦强度 `3.0` 下的肩部颜色值低于 `1.0`，峰值颜色保持一致。
- 修改聚焦强度立即保存并重绘，但不触发 `configureWorkerRequested` 或
  `spatialGridRequested`。
- Debug/Release 构建、CTest、Python 工具测试、模拟服务端自检和
  `git diff --check` 全部通过。

## 非目标

- 不修改 SRP、神经网络或物理连续峰的数值结果。
- 不增加新的线程、协议字段或训练参数。
- 不改造离线音频分析页面。
