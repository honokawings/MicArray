# 48 通道软件波束形成降噪设计

日期：2026-08-02

## 目标

在降噪处理页面增加可选的“48 通道直接处理”模式。该模式直接使用设备既有音频帧中的 CH0–CH47 原始阵元数据，按增强方向 A、抑制方向 B1、B2 的连续实际角度分别执行软件波束形成，再将三路结果送入现有维纳降噪和后处理流水线。

默认保留当前“FPGA 波束形成通道”模式，继续将 CH1、CH2、CH3 解释为 A、B1、B2，保证现有部署和设置兼容。

本功能不改变设备控制协议，不发送 FPGA 模式切换命令，也不占用控制帧保留字段。设备端是否输出 48 路原始阵元数据由既有 FPGA/设备配置负责。

## 方案选择

考虑了三种实现：

1. 整数采样延时求和：实现简单，但 5 cm 阵元间距在 48 kHz 下的角度台阶过粗，无法体现连续实际角度。
2. STFT 频域波束形成：高频相位控制灵活，但需要三路频域权重、重叠相加和额外缓冲，延迟及状态切换复杂。
3. 流式分数延时求和：以插值实现亚采样延时，延迟确定、CPU 负担可控，并能直接使用现有连续角度。

采用方案 3。使用四点三次 Lagrange 插值；48 个阵元、3 个目标方向共享一个因果参考延迟，保证 A、B1、B2 严格时间对齐，适合后续维纳功率估计。

## 设置与界面

在 `NoiseReductionSettings` 中增加：

- `inputMode`：`FpgaBeamformedChannels` 或 `Raw48SoftwareBeamforming`，默认前者。
- `reuseLocalizationVideoCalibration`：是否复用实时声源定位的视频校准，默认关闭。

降噪页面的“方向控制”页签增加“输入处理”区域：

- 处理来源下拉框：`FPGA 波束形成通道（CH1/CH2/CH3）`、`48 通道软件波束形成（CH0–CH47）`。
- “复用声源定位视频校准”复选框，仅在 48 通道直接处理模式可用。
- 说明文字明确指出该选项不配置 FPGA，原始 48 通道输出需由设备端保证。

方向输入继续保存 `double` 连续角度，界面以 0.1° 步进显示。FPGA 兼容模式仍仅在显示接口码和发送方向控制时量化；软件波束形成模式始终使用连续角度，不经过接口码量化。

## 视频投影与校准复用

现有降噪页面默认使用角度线性广角投影，必须保持不变。

只有同时满足以下条件时，降噪视频标记的绘制、点击和拖动才改用声源定位的针孔投影：

- 输入模式为 48 通道软件波束形成；
- “复用声源定位视频校准”已勾选。

复用的数据是 `AppSettings::liveLocalization().camera`。四点校准拟合结果已经写入该相机参数，因此无需复制校准点或建立第二份校准配置。页面切换到复用模式时重新读取最新持久化参数；降噪页面重新激活或刷新设置时也同步读取，避免长期缓存旧值。

未复用时继续使用降噪页自己的中心方位、中心俯仰和水平/垂直视场角。两种投影不可混用：绘制使用哪种投影，反投影点击和拖动就必须使用相同投影。

## 软件波束形成

新增独立媒体类 `FractionalDelayBeamformer`，职责仅包括原始帧解码、延时系数维护和三路波束输出，不包含维纳或 UI 逻辑。

阵列几何复用声源定位的默认 6×8、5 cm、以阵列中心为原点的几何。方向向量沿用现有约定：

```text
x = sin(azimuth) * cos(elevation)
y = sin(elevation)
z = cos(azimuth) * cos(elevation)
```

每个阵元对每个方向的相对延时由阵元位置与方向向量点积计算。声速使用 343 m/s，与当前默认定位参数一致；本次不新增独立声速控件，避免两个页面出现无明确归属的重复参数。

处理流程：

1. 校验负载长度必须是 200 × 48 × 4 字节。
2. 按现有格式将小端 32 位容器右移 8 位，归一化为浮点样本。
3. 将 48 路样本写入跨帧环形历史。
4. 使用预计算的整数延时与四点插值系数产生 A、B1、B2。
5. 每路按 48 归一化，输出与输入帧相同的 200 个样本。

三路使用统一参考延时：以阵列最大理论传播延时为基准，再加入插值保护样本，使任何方向都只读取当前或历史样本。启动后的共同延迟区输出零，不能为某一路单独缩短延迟，否则会破坏维纳滤波的同一时刻功率比较。

目标角度变化时只重算相应权重，不清空音频历史，也不重置整个后处理链，保证拖动方向标记时监听连续。大幅改变方向后，维纳统计会在其既有平滑时间内重新收敛。

## 降噪工作线程数据流

`NoiseReductionWorker` 仍是唯一 DSP 线程，页面队列上限和丢帧策略不变。

FPGA 兼容模式：

```text
48 通道帧 -> 现有解码器 -> CH0 / CH1(A) / CH2(B1) / CH3(B2)
           -> 维纳抑制 -> 可重排后处理 -> 监听/绘图/录制
```

48 通道直接处理模式：

```text
48 通道帧 -> CH0 作为第一阵元观察源
           -> 分数延时波束形成 -> A / B1 / B2
           -> 维纳抑制 -> 可重排后处理 -> 监听/绘图/录制
```

为兼容现有监听、绘图和录制来源，软件波束结果组装成现有逻辑输入：CH0 为第一阵元，CH1 为 A，CH2 为 B1，CH3 为 B2。后续模块无需区分这三路来自 FPGA 还是软件。

切换输入模式或采样率时清空波束形成历史和维纳/后处理状态，防止不同延迟模型的数据混合。仅修改角度时不重置状态。

## 设置持久化与容错

- 旧配置缺少新键时使用 FPGA 兼容模式和“不复用校准”。
- 非法输入模式回退到 FPGA 兼容模式。
- 角度和相机参数继续使用既有清洗、范围约束和非有限值回退规则。
- 直接处理模式收到尺寸错误的帧时丢弃该帧并发出限频警告，不静默回退到 CH1–CH3。
- 直接处理模式不会验证 FPGA 当前是否确实输出原始阵元数据；界面说明和文档明确这一设备前置条件。

## 测试

### 媒体层

- 正前方同相信号经三路同方向波束形成后保持幅度和长度。
- 构造来自非量化角度（例如 17.3°、20.7°）的平面波，匹配方向输出能量明显高于偏离方向。
- 两个落在同一 FPGA 接口码内的实际角度产生不同延时系数/输出，证明没有提前量化。
- A、B1、B2 输出长度相等且共同延迟对齐。
- 跨 200 样本帧边界的插值连续。
- 非法负载、采样率变化和模式切换能安全重置。
- Worker 在两种输入模式下均正确生成监听、绘图和录制阶段数据。

### 设置与界面

- 新设置默认值、保存/读取和非法值回退。
- 直接处理模式启用校准复用控件，兼容模式禁用。
- 未复用时维持角度线性广角投影。
- 复用时绘制与点击均使用实时定位相机参数，并使用连续实际角度配置 Worker。
- 切换模式不发送额外设备控制帧；原有方向发送行为回归通过。
