# 独立演示窗口与可拖动视频分隔条设计

## 目标

修复演示全屏中视频区域随实时刷新逐步改变大小的问题，并彻底消除退出全屏时主窗口经过中等普通窗口的闪跳。

## 根因

当前视频和诊断卡片由 `QHBoxLayout` 自动分配宽度。诊断标签启用了自动换行，实时文本刷新会更新尺寸提示，布局因此反复重新分配视频宽度。

当前演示模式直接将 `MainWindow` 从最大化切换到原生全屏。Windows 在退出原生全屏时会让同一个顶层窗口经过普通状态再恢复最大化；禁止 Qt 客户区绘制无法阻止系统窗口边框的中间状态。

## 设计

### 可拖动且稳定的视频区域

视频和紧凑诊断卡片放入独立的水平 `QSplitter`：

- 分隔条可直接拖动。
- 视频和诊断区都不可完全折叠。
- 诊断标签忽略内容尺寸提示，实时文本更新不得改变分隔比例。
- 首次进入演示模式使用约 `3:1` 的视频/诊断比例。
- 用户拖动后的比例在本次程序运行期间保存，后续进入演示模式时恢复。

### 独立演示全屏窗口

新增独立顶层演示窗口。进入演示模式时，将顶部状态栏和监控中心区域临时迁移到该窗口并全屏显示；主窗口始终保持进入前的普通或最大化状态，不发生任何窗口状态切换。

退出时先抓取独立演示窗口的最后一帧，并用全屏遮罩保持该画面；随后把顶部状态栏和监控中心区域放回主窗口原布局、同步重绘主窗口，最后隐藏独立演示窗口及遮罩。这样既不会显示被迁空的演示窗口，也不会暴露尚未恢复的主布局。由于主窗口一直保持最终状态，Windows 不再有 `FullScreen -> Normal -> Maximized` 的转换路径。

独立窗口支持：

- “退出全屏”按钮；
- 双击视频；
- `Esc`；
- 系统关闭请求。

## 测试

- 进入演示模式后，独立演示窗口处于全屏，主窗口状态和几何保持不变。
- 退出演示模式时，主窗口不产生 `windowStateChanged`，不存在中间普通窗口。
- 视频与诊断区使用水平 `QSplitter`，分隔条可移动。
- 改变诊断文本并处理事件后，分隔尺寸保持稳定。
- 用户调整的分隔比例在退出、再次进入后恢复。
- 现有按钮、视频双击、`Esc`、主题和最小尺寸测试继续通过。
