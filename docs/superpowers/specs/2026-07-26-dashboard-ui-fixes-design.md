# 音视频融合与演示全屏界面修复设计

## 目标

修复音视频融合页和录制页的可读性问题，并调整演示全屏布局及窗口状态恢复：

1. 音视频融合页的视频、音频统计文本之间不再显示无说明的电平进度条。
2. 浅色主题下，录制通道按钮的选中和未选中状态都具有可读的前景色与背景色。
3. 演示全屏右侧显示紧凑的实时协议诊断摘要，用于平衡视频区域比例；告警时间线和日志继续隐藏。
4. 退出演示全屏时一次性恢复进入前的窗口状态，避免先出现普通窗口再跳到最大化窗口。

## 界面设计

### 音视频统计

保留视频统计行和音频统计行，移除二者之间的 `QProgressBar`。音频峰值百分比已经包含在音频统计文本中，不损失信息。

### 录制通道

为 `recordChannel_*` 按钮增加专用对象属性。全局主题样式分别定义未选中、悬停、选中和禁用状态，浅色主题使用深色文字配浅色背景，选中状态使用强调色背景配白字；深色主题保持对应的高对比度配色。

### 演示全屏诊断卡片

普通模式继续使用完整右栏。演示全屏隐藏完整右栏，并在中心内容右侧显示独立的紧凑诊断卡片。卡片复用 `m_protocolStatsLabel` 的实时文本来源，但使用独立标签显示，避免改变普通模式层级。卡片不包含告警时间线、日志或导出操作。

### 窗口状态恢复

进入演示模式前保存完整 `Qt::WindowStates`。进入和退出均通过一次 `setWindowState()` 切换状态，不再组合调用 `showNormal()` / `showMaximized()`。退出时先准备布局可见性，再原子恢复原状态并刷新，避免中间窗口状态被绘制。

## 测试

- 验证音视频统计区域不存在可见进度条。
- 在浅色主题下抓取录制通道按钮，验证未选中和选中文字与背景具有足够差异。
- 验证演示全屏显示紧凑诊断卡片、隐藏完整诊断右栏及告警/日志。
- 验证从最大化窗口进入并退出全屏时，不产生中间 `WindowNoState` 状态。
- 保留并运行现有全屏、主题、最小尺寸和全量测试。
