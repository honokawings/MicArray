# 音频录制与诊断显示增强设计

## 目标

- 将主监控页“交互驾驶舱”更名为“音视频融合”。
- 将累计量、缓冲量和队列量等字节统计统一改为 IEC 自适应单位。
- 支持从 48 通道阵列中任选一个或多个通道，保存为单个同步多通道 WAV。
- 高级帧调试历史除帧前 16 字节和帧尾 16 字节外，再显示帧尾后的实际 TCP 流 16 字节。

## 非目标

- 不改变设备音频协议、播放通道、校准算法或视频解码格式。
- 不把录音写盘并入网络、协议、UI 或现有音频播放线程。
- 不把协议长度字段改为近似值；协议字段仍显示精确字节数。

## UI 设计

主监控页签标题改为“音视频融合”。新增顶层“音频录制”页，避免在 1366x768 下继续压缩已经较密集的监控页。

录音页包含：

- 6x8 可勾选通道矩阵，编号顺序与阵列校准页一致。
- “全选”“清空”“反选”“当前播放通道”快捷操作。
- 保存目录选择和只读路径显示。
- “开始录制”和“停止录制”命令按钮。
- 录制状态、已选通道、持续时间、已写大小、写入速率、队列占用和最近错误。

开始录制要求设备已连接、至少选择一个通道且目标目录可写。断线、退出或写盘失败时自动停止并封口 WAV。停止过程中禁用重复操作，完成后保留最终统计和文件路径。

## 录音架构

新增独立 `AudioRecorder` 组件和录音线程。原始音频 `HostFrame::payload` 在协议分发后并行进入录音组件，播放、波形和校准仍使用现有 `AudioProcessor`。

UI 线程只执行有界入队，不执行解交织或文件写入。录音线程按帧解交织已选通道，并按采样点优先、通道编号升序写入 WAV。队列以字节数限制为 64 MiB；队列无法接收完整帧时停止录制并报告“录音队列溢出”，不静默丢帧。

录音状态机为 `Idle`、`Starting`、`Recording`、`Stopping`、`Error`。组件通过信号报告状态、持续时间、数据字节数、文件字节数、队列字节数和错误。

## WAV 与元数据

每次录音生成一个逻辑多通道录音：

- 采样率来自当前音频设置，默认 48000 Hz。
- 通道数等于勾选通道数，通道顺序按物理编号升序。
- 每个样本使用 32-bit 小端容器，保留设备原始 24-bit 有效数据。
- WAV 使用 `WAVE_FORMAT_EXTENSIBLE`，声明 24 个有效位，通道掩码为 0（阵列通道不套用扬声器位置语义）。
- 同名 JSON 清单记录物理通道编号、采样率、开始/结束时间、帧数、样本数、数据字节数、分段文件和停止原因。

RIFF 数据接近 4 GiB 上限时，在完整音频帧边界自动滚动为 `_part002.wav` 等后续多通道分段。所有分段属于同一个录音会话，并由同一 JSON 清单关联。不会写入截断采样点或半帧。

WAV 头在创建时写入占位长度，正常停止、断线停止和可恢复错误停止时回写 RIFF/data 长度。创建失败或磁盘错误通过 UI 和日志同时报告。

## 自适应字节单位

新增可测试的统一格式化函数：

- 小于 1024：`B`。
- 依次使用 `KiB`、`MiB`、`GiB`、`TiB`，以 1024 为进位。
- 非整数单位保留最多两位小数，避免无意义尾零。
- 速率复用相同规则并追加 `/s`。

适用范围包括累计接收、累计解析、累计丢弃、协议缓冲、待解析队列、音频累计量、录音文件大小、录音队列和写入速率。协议 payload 长度、frameSize、tailOffset 等联调字段继续使用精确 `B` 或原始整数，避免隐藏边界错误。

## 帧尾后 16 字节

`HostFrame` 增加帧尾后预览及完整性标记。协议解析保持媒体帧即时输出，同时维护仅用于调试事件的待预览帧：

- 若当前协议缓冲在帧尾后已有 16 字节，立即填充预览。
- 若不足 16 字节，等待后续 TCP chunk，只延迟调试事件，不延迟音频/视频分发。
- 收到 16 字节后发出调试帧；这些字节仍留在正常解析流中，不被消费两次或计入丢弃。
- 清空协议状态时，未满 16 字节的最后一个调试预览以实际字节数标记为不完整，不伪造内容。

高级帧调试页为最近一帧和每条历史记录增加“帧后 16 字节”。预览继续使用等宽字体；不足 16 字节时明确显示实际数量。

## 错误处理与生命周期

- 未连接、未选通道、目录不可写：不开始录音，保留可操作错误。
- payload 长度不是 38400 字节：录音停止并报告格式错误，避免输出通道错位文件。
- 队列溢出、短写、磁盘空间不足：停止录音，尽力回写 WAV 头和 JSON；错误不会影响 TCP 连接和实时监控。
- 设备断线和应用退出：先停止接收录音帧，再等待录音线程完成封口，最后结束线程。
- 录音期间锁定通道选择、采样率和保存目录；播放通道仍可独立切换。

## 测试

- 字节格式化边界：0、1023、1024、MiB、GiB 和速率。
- WAV：单通道、非连续多通道、交织顺序、头字段、有效位、长度回写和 JSON 通道映射。
- 录音错误：空通道、非法 payload、队列上限、不可写路径和重复开始/停止。
- 协议：同 chunk 和跨 chunk 的帧尾后 16 字节，媒体帧不因调试预览延迟，清空时不完整预览。
- UI：页签名称、录音页控件、通道快捷选择、连接状态对开始按钮的约束、自适应统计文本和历史帧后预览。
- 完整执行现有 C++、Python 测试以及模拟服务端自检，确认协议和模拟工具无回归。
