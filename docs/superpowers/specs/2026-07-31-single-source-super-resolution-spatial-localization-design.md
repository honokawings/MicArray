# 单声源超分辨空间定位与热力图设计

## 背景

当前实时声源定位采用 GCC-PHAT 时差估计与 SRP-PHAT 空间响应。为满足
`640×360` 方向网格的纯 CPU 实时要求，热力图路径将 122 个麦克风对按阵元
位移压缩成 4 类水平或垂直基线，再从每类 GCC 中按理论时延做线性插值。

该实现具有较好的吞吐，但存在以下精度边界：

- 4 类基线没有利用斜向孔径，方位与俯仰之间的联合约束不足。
- 同类麦克风对直接累加，缺少对低信噪比频点、扩散混响和异常通道的可靠度
  判断。
- GCC 只做相邻两个时延采样点的线性插值，峰值存在分数时延偏差。
- 定位输出来自成对 TDOA 的鲁棒最小二乘，热力图峰值来自另一套 SRP 扫描，
  两者不保证使用同一个连续空间极值。
- 热力图逐帧做最小值/最大值归一化，弱背景也可能被拉满；默认 `64×36`
  网格只能把峰值显示在像素中心，无法表达亚网格方向。

本设计只处理阵列正面半球中的一个主声源，不处理多声源分离、声源计数或
近场距离估计。

## 设计目标

1. 定位和热力图共用同一个宽带空间目标函数及连续峰值。
2. 利用 6×8、5 cm 阵列的水平、垂直和斜向孔径，获得亚角度连续方向估计。
3. 对低信噪比频点、扩散混响、少量异常麦克风和短时窄带输入保持稳定。
4. 热力图保留真实空间响应背景，同时在连续峰值附近呈现由局部目标函数
   曲率得到的超分辨峰，而不是对图像做无依据的锐化。
5. 提供“实时增强”和“高精度”两种模式：
   - 实时增强模式在 Release 构建中保持 `640×360`、纯 CPU、中位耗时
     不超过 `100 ms`。
   - 高精度模式使用全部有效基线，Release 中位耗时不超过 `200 ms`。
6. 不新增第三方运行时依赖，保持 Qt 6.5、C++20、MinGW/Ninja 兼容。
7. 保持现有离线定位器源码级扩展接口；不引入动态插件 ABI。

## 不在范围内

- 同时定位两个或更多声源。
- 估计声源到阵列的距离。
- 通过神经网络训练或下载模型改善定位。
- 自动修改现有四点视频校准结果。
- 使用 GPU、CUDA、OpenCL 或平台专用 SIMD 作为正确性前提。

## 方案比较

### 方案 A：多基线相干加权 SRP 与连续精修

保留 SRP-PHAT 对宽带语音和混响的工程鲁棒性，将阵列的等位移麦克风对聚合
为多方向基线；用组内相位一致性作为直达声可靠度；先扫描完整显示网格，再
围绕最强候选做全基线连续精修。

优点是可以复用现有 FFT、线程池和空间响应接口，无需矩阵特征分解；基础图、
定位结果、连续峰值和可信度可以来自同一个目标函数。缺点是实现需要管理
多级缓存、基线选择和局部插值。

### 方案 B：宽带 NormMUSIC

对多个频带构造空间协方差和信号/噪声子空间，再累加归一化 MUSIC 伪谱。
理想条件下峰值很尖，但短窗口、混响、通道幅相误差和协方差快照不足会破坏
子空间估计。48 通道逐频点特征分解还会显著增加纯 CPU 开销。

### 方案 C：稀疏贝叶斯或压缩感知

将单声源方向作为稀疏空间系数求解。它具有较高理论分辨率，但实时迭代成本、
超参数敏感度、内存占用和工程复杂度均高于当前需求。

本项目采用方案 A。方案 B 可以在未来作为新的 `ISoundSourceLocator` 实现，
但不作为本次默认算法。

### 研究依据

- Grondin 与 Michaud 的
  [SRP-PHAT-HSDA](https://arxiv.org/abs/1812.00115)
  说明由粗到细的分层方向搜索可以显著降低实时空间扫描成本。
- Lima 等人的
  [RV-SRP](https://arxiv.org/abs/1407.2351)
  表明稀疏初始扫描后追加局部精细搜索，可以改善精度/计算量折中，并在模拟与
  真实数据中优于固定细网格。
- Garcia-Barrios 等人的
  [SRP-PHAT 带宽与空间分辨率分析](https://arxiv.org/abs/2402.06586)
  从 GCC 采样角度说明过宽频带与粗空间网格会产生空间混叠。本实现因此不把
  显示网格当作最终估计：先限制有效频带和频点可靠度，再以全有效基线连续
  分数时延目标函数精化；临界带宽和单频输入另由宽带相干门控拒绝。

## 总体架构

```text
48 通道音频窗口
  -> 加窗、FFT 与通道质量检测
  -> 单通道相位归一化
  -> 等位移麦克风对分组
  -> 组内相位一致性与频带可靠度加权
  -> 多基线 GCC 缓存
  -> 显示网格快速扫描
  -> 最强单声源候选
  -> 全基线分层连续精修
  -> 峰值曲率、旁瓣比和可信度
  -> 连续 DOA + 稳健归一化热力图 + 超分辨局部峰
```

新增一个独立的 `RobustSrpPhatScorer`，负责频谱、基线、GCC、目标函数时间平滑、
网格扫描和连续精修。`GccPhatLocator` 负责定位器接口、置信度门限以及将同一评分
结果提供给 `locate()` 和 `evaluateSpatialResponse()`。时间平滑必须作用于通道相位
与组相关，不允许在连续峰求解后单独平滑坐标。这样可以单独测试评分器，
也避免继续扩大现有 `gccphatlocator.cpp`。

## 多基线相干加权

### 基线分组

对配置中的麦克风位置枚举无序麦克风对。将位移向量规范到固定半平面：

- `dy > 0` 时保留原符号。
- `dy == 0 && dx > 0` 时保留原符号。
- 其他情况交换麦克风顺序并反转位移。

按 `1e-9 m` 量化后的 `(dx, dy, dz)` 聚合。默认 6×8 平面阵列会产生水平、
垂直和斜向的多种唯一位移，而不是当前仅有的 4 类。每组保留成员麦克风对、
位移长度、方向、冗余对数和最大物理时延。

实时增强模式从全部组中确定性选择最多 32 组。选择时将基线角度划分为
12 个方向桶、长度划分为短/中/长三个孔径桶，从各桶轮询选择冗余度最高的
组，保证方向和孔径覆盖。高精度模式使用所有至少含一个有效麦克风对的组。

### 通道质量

每个音频窗口先计算各通道加窗能量。使用 48 通道能量中位数作为基准：

- 非有限样本或能量小于 `1e-12` 的通道无效。
- 能量相对中位数低于 `-24 dB` 或高于 `+18 dB` 的通道降权为零。
- 其余通道按与中位数的偏差获得 `0.25..1.0` 的平滑质量权重。

只有两个端点都有效的麦克风对参与聚合。单个异常通道因此只影响包含该通道
的少量对，不会使整个空间响应失效。

### 相干加权 PHAT

对麦克风 `m` 的频谱定义：

```text
U_m[k] = X_m[k] / max(|X_m[k]|, epsilon)
```

同一位移组 `g` 的圆均值为：

```text
A_g[k] = sum(q_i q_j U_i[k] conj(U_j[k])) / sum(q_i q_j)
```

其中 `q_i`、`q_j` 是通道质量。`|A_g[k]|` 是具有相同理论相位差的冗余
麦克风对之间的相位一致性。直达单平面波接近 1，扩散混响、噪声或异常通道
会使其下降。

频点可靠度采用连续软门限：

```text
r_g[k] = smoothstep(0.15, 0.65, |A_g[k]|)
C_g[k] = r_g[k] * A_g[k] / max(|A_g[k]|, epsilon)
```

只处理 `250..8000 Hz`，并在上下边界各使用 150 Hz 余弦过渡带。这样不会
由频带外噪声形成伪峰，也不会在边界产生明显相关振铃。组频谱补齐共轭负频率
后执行逆 FFT，得到相干加权 GCC。评分时每组先按有效频点可靠度归一化，再在
组之间等权累加，避免冗余短基线完全淹没长孔径信息。

若一个窗口的有效通道少于 32、有效基线组少于 12，或可靠频点覆盖率低于
15%，本帧不输出定位和热力图。

## 空间评分与连续精修

### 完整显示网格

`prepareSpatialResponseGrid()` 为每个方向和每个选中基线组预计算理论分数
时延。完整网格扫描使用四点三次卷积插值读取 GCC，取代现有两点线性插值。

实时增强模式使用最多 32 个方向/孔径均衡的组扫描完整网格。高精度模式使用
全部有效组。扫描仍按连续行块投递到专用 `QThreadPool`，保留一个逻辑核心给
主音视频链路。

### 分层连续精修

完整网格的最大响应只作为初始候选。连续精修使用全部有效基线组和八点
Hann-windowed sinc 分数时延插值，不受显示网格分辨率限制。

精修在方位角/俯仰角切平面上执行确定性的 3×3 模式搜索：

1. 初始步长取相邻网格方向间距和 `2°` 的较大值，并限制在 `2°..6°`。
2. 计算中心及八个邻点，移动到得分最高的点。
3. 若中心仍为最高点，将步长减半。
4. 步长小于 `0.05°`、连续两轮提升小于 `1e-5` 或达到 40 轮时停止。
5. 所有候选夹紧到阵列正面半球及当前可搜索方向范围。

精修后的连续方向存入本窗口缓存。`locate()` 与
`evaluateSpatialResponse()` 对同一个 `centerSample` 必须复用该结果，
不允许分别产生两个峰值。

### 峰值质量

在连续峰值的方位、俯仰方向分别以 `±0.25°` 和 `±0.5°` 采样局部目标函数，
拟合二维负 Hessian。只有 Hessian 为正定时才生成超分辨峰宽。

同时计算：

- 峰旁瓣比：排除峰值 `5°` 邻域后的最高响应与主峰之比。
- 局部曲率：Hessian 的最小特征值。
- 相干覆盖率：参与评分的组内真实可靠频带权重，而不是通过门限后的布尔组数。
- 全阵列相干率：候选方向补偿理论时延后，48 通道在整个有效频带中的相位一致性。
- 通道覆盖率：有效通道数占 48 通道的比例。

最终置信度由以上各项的有界几何平均构成；主峰与旁瓣必须使用相同的全有效组、
八点 sinc 插值和归一化目标函数。任意关键项接近零都会显著降低
置信度，避免用其他高分项掩盖单项失效。置信度低于配置门限时
`locate()` 返回空结果；空间响应可以保留低强度背景用于诊断，但不生成
连续超分辨峰。

## 热力图归一化与超分辨呈现

### 稳健归一化

评分器返回完整网格的非负响应。使用中位数作为背景基线、`99.5%` 分位作为
稳健主体上限：

```text
body = 0.98 * pow(clamp((value - median) / (p99_5 - median), 0, 1), 0.75)
head = 0.98 + 0.02 * clamp((value - p99_5) / (maximum - p99_5), 0, 1)
display = value <= p99_5 ? body : head
```

若分位范围小于 `1e-9`，视为空间响应不足。顶部保留的 2% 色阶避免多个
`P99.5` 以上网格全部饱和，从而保持真实最大峰排序；最大值只影响这段很窄的
头部色阶，不会像逐帧最小/最大归一化那样把随机背景强制拉到全色阶。

`LiveLocalizationWorker` 不再对已经归一化的结果重复做最小/最大缩放或独立
时间平滑；所有时域平滑仅在评分器的通道相位与组相关目标上执行，确保网格峰、
连续峰、Hessian 和可靠度完全同源。网格、算法、更新周期、置信门限、启停
状态、无效采样格式或时间戳倒退时清空时间平滑状态并发布空响应；页面以统一的
配置 generation 同时拒绝过期定位和过期热力图。

### 局部真实响应补算

评分器在连续峰值周围至少 `±6°`、且不小于三个显示网格单元的区域，使用
全部有效基线和八点 sinc 插值重新计算网格响应，并替换快速扫描值。该区域
仍是真实 SRP 目标函数，不是图像滤镜。

### 亚网格峰

`SpatialResponseResult` 和 `LiveSpatialResponse` 增加：

- 连续峰值方向。
- 方位与俯仰标准差。
- 方位/俯仰相关系数。
- 峰旁瓣比。
- 是否允许呈现超分辨峰。

`LiveLocalizationView` 先对稳健归一化网格做双线性标量插值，再映射颜色。
如果连续峰可信且局部 Hessian 正定，则把 Hessian 的二次似然模型采样到峰值
附近，并与真实网格响应取较大值。该模型的中心严格由连续 DOA 投影得到，
二维协方差通过完整的方位/俯仰投影基向量映射到视频，保留 Hessian 交叉项、
相机滚转和非中心透视；幅度不超过实际主峰。低可信度时不添加
二次模型，因此不会制造虚假尖峰。

热力图内部渲染尺寸至少为 `256×144`，最高为用户配置的
`640×360`，最后按视频区域平滑缩放。即使用户仍使用默认 `64×36` 方向网格，
也可以显示连续峰的亚网格中心。成品热力图按响应、相机与目标尺寸缓存，
视频帧重绘不重复生成标量图。

## 模式与配置

新增枚举：

```cpp
enum class SpatialResolutionMode {
    RealtimeEnhanced,
    HighPrecision,
};
```

`LiveLocalizationSettings` 增加 `spatialResolutionMode`，默认
`RealtimeEnhanced`。实时定位页面增加“空间精度”组合框：

- `实时增强（10 FPS）`
- `高精度（约 5 FPS）`

模式变化立即重建定位器和空间缓存，并通过 `QSettings` 持久化。离线音频分析

在重建定位器时明确传入各自模式，评分器不直接读取应用设置。

模式，不影响其他实时定位设置。

## 接口与数据流

### `RobustSrpPhatScorer`

新增文件：

- `src/analysis/robustsrpphatscorer.h`
- `src/analysis/robustsrpphatscorer.cpp`

公开职责：

```cpp
class RobustSrpPhatScorer
{
public:
    bool configure(const LocatorConfiguration &configuration,
                   QString *errorMessage = nullptr);
    void prepareGrid(const SpatialResponseGrid &grid);
    bool prepareWindow(const MultiChannelAudioWindow &window);
    RobustSpatialEstimate estimate(const SpatialResponseGrid *grid = nullptr);
    void reset();
};
```

`RobustSpatialEstimate` 包含可选连续方向、网格原始响应、可靠度、峰旁瓣比、
角度标准差、有效通道数和有效基线组数。评分器不依赖 UI、`AppSettings` 或
视频投影。

### `GccPhatLocator`

`GccPhatLocator` 保留现有稳定 ID `gcc-phat-tdoa`，避免已有配置失效。描述文本
更新为“多基线相干加权 SRP、连续峰值精修与鲁棒远场方向估计”。

同一音频窗口只执行一次频谱和基线构建：

- 首先调用 `locate()` 时，评分器准备窗口并从内部半球种子网格产生连续方向。
- 随后调用 `evaluateSpatialResponse()` 时复用窗口缓存，只补充显示网格扫描。
- 首先调用 `evaluateSpatialResponse()` 时同时生成连续方向；之后
  `locate()` 复用它。

内部种子网格覆盖方位、俯仰 `-90°..90°` 且只保留正面方向。实时增强模式
使用 `5°` 间距，高精度模式使用 `2°` 间距；两者随后都执行同一套全基线
连续精修。因此定位不会依赖当前视频视场，也不会因显示网格较粗而失去全局
候选。

缓存键继续包含 `centerSample`、采样率、采样数、通道数和首通道数据地址。
任何一项变化都使窗口缓存失效。

### 结果类型

`SpatialResponseResult` 与 `LiveSpatialResponse` 保持现有字段，并追加以下
有默认值的峰值元数据：

```cpp
bool hasRefinedPeak = false;
ScanDirection refinedPeak;
double azimuthStandardDeviationDegrees = 0.0;
double elevationStandardDeviationDegrees = 0.0;
double peakToSidelobeRatio = 0.0;
```

已有自定义 `ISpatialResponseProvider` 不需要提供元数据，UI 在
`hasRefinedPeak == false` 时仅显示普通网格。

## 错误处理

- 非有限样本、错误通道数、错误窗口长度或采样率不匹配：返回空结果。
- 基线分组不足、可靠频点不足或通道覆盖不足：返回空定位和零可靠度。
- 连续搜索遇到非有限响应：丢弃该候选；全部候选无效则返回空结果。
- Hessian 非正定：仍可返回连续方向，但不生成超分辨峰宽。
- 高精度计算超过更新周期不会阻塞网络、播放、录音或视频；沿用实时定位旁路
  的有界队列并丢弃新旁路帧。
- 模式切换时清空评分器、目标函数平滑和热力图平滑，避免不同算法状态混合；
  无效窗口和设备时间戳倒退同样中断历史状态。

## 测试策略

所有生产行为按 TDD 实现，先观察目标测试因缺少新能力而失败。

### 算法精度

- 非网格合成平面波覆盖中心、边缘、正负方位和正负俯仰。
- 无噪声连续方向误差不超过 `0.5°`。
- 连续峰值与定位输出的球面夹角不超过 `0.1°`。
- 显示网格的局部补算峰必须落在离连续峰最近的网格单元。

### 鲁棒性

- 1、2、4 个通道替换为独立噪声时，方向误差不超过 `1.5°`。
- 5 dB 加性白噪声和一个幅度 0.35、额外时延 3 ms 的反射同时存在时，方向
  误差不超过 `2.0°`。
- 纯静音、48 路互不相关噪声、少于 32 个有效通道时不输出可信峰。
- 单频和窄带输入不出现非有限值；若空间歧义过大则降低可信度而不是输出
  高可信尖峰。

### 可视化和配置

- 默认低分辨率网格下，渲染峰中心与连续方向投影位置的距离不超过
  1 个内部渲染像素。
- 非正定 Hessian 或低可信度结果不生成超分辨局部模型。
- 两种模式可保存、载入，非法值独立回退。
- 模式切换会清空旧热力图并重建定位器。

### 性能

Release 构建对 `640×360` 网格预热后连续测量五帧并取中位数：

- 实时增强模式“定位 + 热力图”不超过 `100 ms`。
- 高精度模式“定位 + 热力图”不超过 `200 ms`。
- 所有结果必须为有限值。

Debug 构建只使用放宽后的 `1500 ms` 正确性上限，避免把未优化构建当作实际
性能结论。

## 验收标准

实现只有同时满足以下条件才算完成：

1. 定位和热力图对同一窗口报告同一连续单声源峰值。
2. 无噪声非网格合成声源误差不超过 `0.5°`。
3. 规定的异常通道、噪声和单反射测试达到对应误差上限。
4. 默认低分辨率热力图可以显示亚网格连续峰中心。
5. 低可信度输入不产生伪高置信尖峰。
6. 两种模式的 Release 性能达到各自上限。
7. 全量 C++/Python 测试、模拟服务端自检和 `git diff --check` 通过。
8. `doc/Readme.md` 已同步算法、配置、测试和变更记录。
