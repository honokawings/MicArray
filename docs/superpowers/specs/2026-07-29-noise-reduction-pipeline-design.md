# 降噪数据流与方向标记拖动设计

## 目标

在现有降噪处理页面和独立工作线程基础上，增加可排序的实时后处理数据流、LogMMSE 与 AGC 节点、页签式控制区，以及普通/演示全屏视频中的方向标记拖动。所有设置需要持久化，并保持当前未提交功能的行为不回退。

## 已确认交互

- 右侧控制区加宽，内部使用“数据流”“监听”“方向控制”三个页签。
- 降噪抑制固定为第一个数据流节点；带通滤波、LogMMSE、AGC 可任意排序。
- LogMMSE 和 AGC 均支持独立旁路。
- 方向标记在拖动期间连续更新实际角度，松开鼠标时才量化并发送最终方向数据。
- 普通页面与演示全屏页面的方向拖动行为一致，且共享方向状态。
- 监听增益范围扩大为 `-60～+48 dB`。

## 数据流模型

实时工作线程中的主音频路径为：

`增强方向 A → 固定降噪抑制 → 可排序后处理节点 → 最终降噪输出`

降噪抑制继续使用原始 B1、B2 作为参考输入。它固定在第一位，但保留启用开关、自适应/固定参数维纳选择、单点/双点模式及三个抑制系数。

后处理节点由稳定枚举标识：

- `BandPass`
- `LogMmse`
- `AutomaticGainControl`

配置中只保存三个后处理节点的顺序。加载配置时去重、过滤非法值，并按默认顺序补齐缺失节点。所有 DSP 状态仅由降噪工作线程拥有；界面只提交完整配置快照。

“降噪处理后音频”表示整条数据流的最终输出。选择第一个阵元、A、B1、B2 作为监听或绘图源时仍读取对应原始解析音频。

## LogMMSE

LogMMSE 使用 Ephraim–Malah 最小均方误差对数谱幅度估计：

- 512 点 Hann 窗 STFT。
- 50% 重叠并使用重叠相加重建。
- decision-directed 先验信噪比估计。
- 在线平滑噪声功率估计，并根据后验信噪比限制含语音帧的噪声更新。
- 默认先验信噪比平滑系数 `0.98`。
- 默认噪声功率平滑系数 `0.95`。
- 默认最小增益 `-20 dB`。
- 节点旁路时不改变样本、不更新状态；重新启用、采样率/参数/顺序变化时重置状态。

处理器负责缓存不足一帧的输入，并保证每次调用返回与输入等长的连续样本。所有非有限中间结果都回退为有限的安全值。

## AGC

AGC 使用 RMS 包络控制：

- 目标电平默认 `-18 dBFS`。
- 最大增益默认 `+30 dB`。
- 最大衰减默认 `-20 dB`。
- 启动时间默认 `20 ms`。
- 释放时间默认 `300 ms`。
- 末端默认峰值上限 `-1 dBFS`。
- 节点旁路时不改变样本、不更新状态；重新启用、采样率/参数/顺序变化时重置状态。

增益按包络平滑并逐样本应用，最终使用峰值限幅避免超出有效浮点音频范围。

## 界面

右侧面板使用可拖动分隔线，默认宽度约 520 像素、最小宽度 440 像素。面板内部使用 `QTabWidget`：

### 数据流

- 使用节点卡片列表展示处理顺序。
- 降噪抑制节点固定首位，没有拖动手柄。
- 带通、LogMMSE、AGC 节点可拖动排序。
- 每个节点显示启用状态和参数摘要。
- 选择节点后，下方参数堆栈显示对应编辑器。
- 放下节点时一次性更新配置、重建处理顺序并保存。

### 监听

- 监听启用开关。
- 监听音源。
- `-60～+48 dB` 监听增益。

### 方向控制

- A/B1/B2 目标选择和连续角度。
- 量化码显示与手动发送。
- 标记显示开关。
- 实际角度映射。
- 视频视角参数。

方向、映射和视角数值控件继续屏蔽鼠标滚轮。

## 方向拖动

视频控件按投影结果计算三个标记的屏幕坐标。左键按下时：

1. 如果鼠标位于标记命中半径内，选择最近标记并开始拖动；
2. 标记重叠且距离相同时优先选择当前方向目标；
3. 如果未命中标记，保留现有“点击设置当前目标”的行为。

拖动时将视频归一化坐标转换为连续方位角和俯仰角，只更新界面与共享设置。松开时发出完成信号，由页面统一量化并发送一次全部六个方向控制值。普通视频和全屏视频使用独立控件实例，但由页面同步同一份设置，避免重复发送和跨窗口控件共享。

## 持久化与兼容

保存：

- 后处理节点顺序；
- LogMMSE 启用状态和参数；
- AGC 启用状态和参数；
- 当前数据流节点和控制页签；
- 现有降噪、带通、监听、方向、映射和视角设置。

旧配置缺少新键时使用默认节点顺序和默认参数。非法数值恢复默认值，非法节点顺序进行规范化。监听增益合法上限从 `+24 dB` 提高至 `+48 dB`。
