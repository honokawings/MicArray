# 降噪标记角度线性广角投影修复设计

## 问题与根因

降噪页面默认水平和垂直视场角均为 `180°`，但现有标记绘制、视频点击和标记拖动仍使用针孔相机投影。代码为绕开针孔模型在 `180°` 时的奇点，将视场角强制夹到 `179°`；这会把绝大多数方向压缩到画面中心，并让靠近边缘的少量像素对应接近 `±90°` 的巨大角度变化。恰好位于 `±90°` 的方向还会被判断为不在相机前方。

## 修复范围

- 为方向投影模块新增一对独立的角度线性广角正反投影接口。
- 降噪视频标记的绘制、点击设置和拖动更新全部切换到该接口。
- 音频分析照片、实时声源定位、四点视频校准继续使用现有针孔相机投影，不改变已有校准数据语义。
- 不修改方向控制码量化、实际角度映射范围、发送时机和配置存储格式。

## 角度线性模型

先根据相机中心方位、中心俯仰和滚转角建立相机局部的前、右、上基向量。将声源单位方向投影到局部坐标后计算：

```text
水平角 = atan2(局部右分量, 局部前分量)
垂直角 = atan2(局部上分量, sqrt(局部右分量² + 局部前分量²))

x = 0.5 + 水平角 / 水平视场角
y = 0.5 - 垂直角 / 垂直视场角
```

反投影使用：

```text
水平角 = (x - 0.5) × 水平视场角
垂直角 = (0.5 - y) × 垂直视场角
```

再由局部水平角、垂直角和相机基向量恢复世界方向。该模型在有效画面范围内正反变换互为逆运算。

## 边界与有效性

- 水平、垂直视场角允许 `1° < FOV ≤ 180°`。
- 水平 `180°` 时，画面左边缘、中心和右边缘分别对应相机中心方位的 `-90°`、`0°`、`+90°`。
- 垂直 `180°` 时，画面上边缘、中心和下边缘分别对应中心俯仰的 `+90°`、`0°`、`-90°`。
- 方向在视场范围内时显示实际标记；超出范围时沿中心到投影点的方向显示在画面边缘。
- 移除降噪页面当前 `179°` 安全夹紧和中心 `0.002` 归一化吸附，避免人为角度压缩和中心附近的非连续误差。
- 由于鼠标位置以屏幕像素表示，最终角度精度只受视频显示区域分辨率限制。

## 接口

在 `analysis/directionprojection.*` 中新增：

```cpp
ProjectionResult projectDirectionAngular(
    const SoundSourceDirection &direction,
    const CameraViewSettings &camera);

ScanDirection unprojectVideoPointAngular(
    const QPointF &normalizedPoint,
    const CameraViewSettings &camera);
```

现有 `projectDirection()` 和 `unprojectVideoPoint()` 保持针孔模型及行为不变。

## 数据流

```text
标记角度
  → projectDirectionAngular()
  → 归一化视频坐标
  → 视频显示坐标

视频点击/拖动坐标
  → 归一化视频坐标
  → unprojectVideoPointAngular()
  → 实际方位角/俯仰角
  → 映射范围夹紧
  → UI、保存及最终控制发送
```

普通页面和演示全屏页面继续使用同一处理函数，因此行为和角度完全一致。

## 测试

1. 投影测试验证默认中心下，`180°` 水平视场的 `-90°/0°/+90°` 精确对应 `0/0.5/1`。
2. 验证非零中心角、滚转角和常用内部方向的正反投影往返误差。
3. UI 点击测试验证画面 75% 水平位置在 `180°` 视场下得到约 `+45°`，不再跳到接近 `+90°`。
4. UI 拖动测试验证释放后的实际角度和标记反投影位置一致，并保持只在释放时发送一次。
5. 完整运行分析、媒体、配置、UI及工具测试，确认现有针孔投影用户未受影响。

## 非目标

- 不增加投影类型切换控件。
- 不迁移或重算照片、实时定位和四点校准数据。
- 不修改麦克风阵列声源定位算法或方向控制接口。
