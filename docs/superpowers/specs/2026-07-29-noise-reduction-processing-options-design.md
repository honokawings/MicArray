# 降噪算法与输出后处理增强设计

## 目标

在现有实时降噪页面中保留自适应维纳滤波，同时新增默认启用的固定参数维纳算法、可选输出带通滤波、监听开关，并降低方向及视角参数的滚轮误操作风险。所有新增参数必须本地持久化，且不改变原始四通道输入定义和独立工作线程边界。

## 算法选择

新增 `NoiseReductionAlgorithm`：

- `FixedParameterWiener`：默认值。
- `AdaptiveWiener`：保持当前自适应多参考维纳实现。

两种算法共用现有 1024 点 STFT、512 点步长、平方根 Hann 窗和重叠相加输出。切换算法、抑制模式或算法参数时重置降噪器内部状态，避免不同算法的统计量或重叠数据互相污染。

固定参数维纳逐频点使用：

```text
Pe  = |Xe|²
Ps1 = |Xs1|²
Ps2 = |Xs2|²

单点：G = Pe / (Pe + C1 * Ps1)
双点：G = Pe / (Pe + CB1 * Ps1 + CB2 * Ps2)
Y = G * Xe
```

`C1` 默认 `3.0`，`CB1` 和 `CB2` 分别默认 `5.0`，三者可独立设置。分母接近零时输出该静音频点的零值，非静音且无抑制参考时增益保持为 1；最终样本继续执行有限值检查和 `[-1, 1]` 饱和保护。

## 带通后处理

新增独立、带状态的 `BandPassFilter`，由二阶 Butterworth 高通和二阶 Butterworth 低通级联构成，总阶数为四阶。它只处理维纳算法生成的“降噪输出”，位置为：

```text
维纳降噪 -> 可选带通 -> 降噪历史/频谱 -> 降噪监听输出
```

其他可监听或绘图的原始源不经过该滤波器。滤波关闭时严格旁路。预设为：

- 人声：100–8000 Hz。
- 音乐：40–16000 Hz。
- 自定义：由用户编辑上下限频率形成。

滤波器默认关闭，默认预设为人声。频率根据实际采样率校验，必须满足 `0 < low < high < Nyquist`；非法持久化数据按字段回退到默认值。采样率、开关或上下限变化时重置滤波状态。

## 监听控制

新增 `monitorEnabled`，默认开启以兼容现有行为。关闭时工作线程立即停止并释放 `QAudioSink`，但继续执行降噪、历史缓存、波形和频谱计算。重新开启后按需重建输出设备。

## 默认值与视角安全

降噪页面的方位角和俯仰角实际映射默认均为 `-90°～90°`。降噪页面的水平和垂直视场角默认均为 `180°`；设置值按 `180°` 显示、保存和载入，而视频投影部件在计算前把视场角安全限制到 `179°`，避免针孔模型在 180° 的奇点。该默认值只作用于降噪页面，不改变音频分析和实时定位页面的相机默认值。

## 界面与防误操作

算法区新增算法下拉框和三个抑制系数输入框；根据单点/双点模式显示或启用相关系数。输出区新增监听开关、带通开关、预设下拉框、上下限频率输入框。

方向 A/B1/B2 的实际角度、实际角度映射以及视频视角参数的数值控件忽略鼠标滚轮事件，但保留键盘输入、控件按钮和直接编辑。抑制系数、滤波频率和监听增益不受该规则影响。

## 配置与兼容

`AppSettings` 保存和载入算法、三个系数、监听开关、带通开关、预设和上下限频率。旧配置缺少这些键时自动采用新默认值。所有数值在载入和保存前逐字段校验，单个非法字段不得导致其他合法字段丢失。

## 验证

- 固定参数维纳的单点、双点独立系数、静音和无参考输入。
- 自适应算法回归行为。
- 带通旁路、通带/阻带、预设和采样率边界。
- 工作线程中后处理位于降噪后且频谱读取处理结果。
- 监听关闭不启动输出设备并继续发布图表。
- 新配置持久化、旧配置迁移、非法字段独立回退。
- 界面默认值、控件可见性及指定数值控件的滚轮屏蔽。
