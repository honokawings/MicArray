# 实时定位可信热力图与神经环形伪影修复设计

## 问题与根因

实时定位当前把两类含义不同的数据同时呈现为高饱和热力图：空间响应网格会按本帧
中位数和高分位数归一化，因此只要存在数值起伏，就必然出现接近 1.0 的相对峰值；
“可信声源”则还要求通道覆盖、相干性、峰旁瓣比、曲率和可靠度全部通过门限。
因此不可信候选也可能显示为醒目的红色峰值，而状态正确地提示“未检测到可信声源”。

神经主峰增强只修改主峰 3σ 椭圆内部，内部肩部被明显压低，3σ 外仍保留原始
热力图，但边界没有过渡。当原始响应在边界附近仍较高时，内外数值发生跳变，
显示为围绕红色核心的绿色圆环或椭圆环。

## 方案选择

- 不采用降低可信度门限：这会把显示问题转化为物理误报。
- 不采用完全隐藏不可信热力图：这会丢失候选分布的诊断价值。
- 采用显式可信度契约：工作线程以本帧实际输出方向为唯一可信标志；视图对不可信
  候选保留空间形状，但将强度限制为冷色弱显示；状态同时给出候选可靠度和配置门限。
- 神经增强在 2σ 至 3σ 之间使用 smoothstep 从锐化值平滑恢复到原始值；3σ 外逐值
  不变，核心 2σ 内保持原有锐化效果。

## 数据契约

`LiveSpatialResponse` 新增 `trustedDirection`。它只由
`LiveLocalizationWorker::analyzeLatest()` 根据同一分析窗口的 `directions.isEmpty()`
设置，不能由热力图最大值、神经标志或 UI 推断。空响应默认不可信。

可信结果按现有热力图焦点指数绘制。不可信结果先应用焦点指数，再乘固定显示系数
`0.35`，使允许范围内任意焦点指数的最大相对峰都保持在蓝绿冷色区；这只影响
显示，不改动声学网格、定位可靠度和后续算法输入。

当网格有效但方向不可信时，状态显示候选可靠度百分比和可信门限百分比；可信时仍
显示“实时声源定位正常”。没有有效网格时沿用空间响应不足/数值无效的错误状态。

## 神经主峰边界

对 Mahalanobis 半径平方 `r²`：

- `r² <= 4`：使用现有 `max(shoulder, kernel)` 锐化值。
- `4 < r² <= 9`：使用 `smoothstep(4, 9, r²)` 在锐化值和原始值之间插值。
- `r² > 9`：原始 float 值逐值不变。

这样 3σ 边界处锐化结果严格等于原始响应，不再形成不连续环；2σ 内主峰收缩和
最终方向对齐逻辑不变。

## 测试与验收

- 分析测试构造有有效空间响应但可靠度门限为 1.0 的窗口，验证仍发布候选网格、
  `trustedDirection == false`，且状态包含候选可靠度和门限。
- UI 测试对相同最大值分别传入可信/不可信标志，验证可信峰保持红色，不可信峰为
  冷色，且不修改输入网格。
- 数值测试构造跨越 3σ 的高肩部响应，验证边界连续、3σ 外逐值不变、核心仍聚焦。
- 运行 Debug 构建、全量 CTest、Python 工具测试、模拟设备自检和 `git diff --check`。

## 约束

- 不改变默认可信度门限，不把不可信候选提升为定位结果。
- 不增加 GPU、第三方依赖或新线程。
- 不改变现有视频投影、校准和热力图网格分辨率。
- 不回滚、覆盖或丢弃工作区已有改动；不创建分支、不暂存、不提交。
