# 实时热力图可调方向网格设计

## 目标

在“声源定位”页面允许用户独立调整真实空间响应热力图的方向网格宽度和高度，最大支持 `640×360`，并在下次启动时恢复。

## 设计

- 在 `LiveLocalizationSettings` 增加 `heatmapGridColumns` 和 `heatmapGridRows`，默认值分别为 `64`、`36`。
- 宽度合法范围为 `16..640`，高度合法范围为 `9..360`；读取到非法本地配置时仅将对应字段恢复为默认值。
- 页面在实时定位设置区增加两个整数输入框。用户修改任一参数后立即保存配置并按当前相机视角重新生成方向网格。
- 网格不再根据视频宽高比自动推导高度；视频首次到达或尺寸变化时仍会使用用户配置重新生成网格。
- 工作线程和 `ISpatialResponseProvider` 接口保持不变，继续通过 `SpatialResponseGrid` 接收任意合法网格。

## 性能与错误处理

`640×360` 包含 230,400 个扫描方向，计算成本显著高于默认 `64×36`。现有独立线程和 32 帧有界音频旁路继续隔离主播放、录音、视频和 UI；当定位线程处理较慢时只丢弃新的分析旁路帧，不阻塞其他功能。

## 测试

- 配置保存后可完整恢复两个网格参数。
- 越界宽度和高度分别回退默认值。
- 页面暴露两个输入框，显示保存值且最大值为 `640`、`360`。
- 修改输入框后配置持久化。
